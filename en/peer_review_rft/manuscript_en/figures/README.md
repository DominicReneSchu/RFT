# Figures Directory

Figures directory for `rft_manuscript_en_iop.tex`.

Place figure files here before compiling. See `\graphicspath` directive
in the main `.tex` file (`rft_manuscript_en_iop.tex`).

## Required figure files

The following figures are referenced via `\includegraphics` in the manuscript:

| File | Section | Caption (abbreviated) |
|------|---------|-----------------------|
| `plot.png` | Monte Carlo | Main dielectron mass spectrum plot |
| `hist_mc_vs_real_hits.png` | Monte Carlo | Histogram: simulated vs. real hit counts |
| `pvalue_curves.png` | Monte Carlo | p-value curves across KDE bandwidths and seeds |
| `heatmaps_hits.png` | Monte Carlo | Hit count heatmaps |
| `figure_1.png` | FLRW | Coupling efficiency vs. H₀ scan |
| `figure_2.png` | FLRW | Additional FLRW result |
| `h0_scan.png` | FLRW | H₀-dependent d_η scan |
| `hubble_tension.png` | FLRW | Hubble tension comparison |
| `cmb_comparison.png` | CMB | CMB spectrum comparison |
| `cmb_chi2_scan.png` | CMB | χ² scan of CMB parameters |

## Generating figures

Most figures can be regenerated by running the corresponding simulation
scripts in the `en/facts/` directory. Refer to the individual `README`
files in each simulation subdirectory for instructions.
