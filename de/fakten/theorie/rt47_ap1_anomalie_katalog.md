## 3. Priorität 1 — Koide-Formel (A1)

**Beobachtung (PDG 2022):**
```
m_e   = 0,51099895 MeV/c²
m_μ   = 105,6583755 MeV/c²
m_τ   = 1776,86 MeV/c²
```

**Koide-Formel:**
```
Q = (m_e + m_μ + m_τ) / (√m_e + √m_μ + √m_τ)² = 0,66666(1) ≈ 2/3
```

**Numerisch:** Q = 0,66661... — Abweichung von 2/3: < 0,007%

**Warum ideal für RFT:**
- Kein bekannter SM-Mechanismus, der Q = 2/3 erklärt
- Keine freien Parameter — vollständige Vorhersage
- Folgt aus einer Symmetriebedingung (Rotation auf Kreis in √m-Raum)
- Natürliche Verbindung zu A3 (rationale Resonanzverhältnisse) + A7 (G_sync-Invarianz)
